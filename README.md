# Vidriería Rivera · Sitio Web Oficial

Sitio web y landing page oficial de **Vidriería Rivera** (Montevideo, Uruguay).

Desarrollado como una aplicación web estática optimizada para dispositivos móviles, con enfoque en velocidad de carga y contacto directo vía llamada telefónica y WhatsApp.

## 🚀 Tecnologías

* **HTML5 semántico** con metadatos OpenGraph y microdatos Schema.org (`LocalBusiness`).
* **CSS3 moderno** responsive con enfoque Mobile-First.
* **JavaScript Vanilla** para interactividad ligera y seguimiento de eventos.
* Sin dependencias externas ni procesos de compilación.

## 📁 Estructura del Repositorio

```text
├── index.html       # Estructura, estilos y lógica del sitio
├── img/             # Fotografías optimizadas y logotipo
├── robots.txt       # Directivas para motores de búsqueda
├── sitemap.xml      # Mapa del sitio XML
└── README.md        # Documentación del proyecto
```
